# 梨花下载器 · Rika Downloader

项目主页：[GitHub · Rika Downloader](https://github.com/Furude-rika-mipa/rika-downloader)

一个在电脑本地运行的视频下载工具。粘贴视频链接、选择画质后，可以查看下载进度并保存到自己的电脑。

支持 X / Twitter、抖音、小红书、B站、YouTube、央视频，以及部分其他网页和 MP4 / M3U8 / MPD 直链。**网站规则、网络、登录状态和视频权限都会影响结果，并非所有链接都能下载。**

请只下载自己有权保存的内容。

Windows 压缩包可从 [GitHub Releases](https://github.com/Furude-rika-mipa/rika-downloader/releases) 下载：

## Windows 版功能

- Windows 桌面程序，有独立图标和原生控件，直接双击 EXE 打开。界面不使用浏览器或 WebView。
- 桌面界面使用黑白灰配色、顶部四色细条和刻度式进度条。默认跟随系统浅色 / 深色，右上角可切换当前窗口的主题；完成、失败和下载中使用紧凑列表显示。
- 启动时立即显示窗口和准备状态，自动连接本目录的下载引擎；服务只监听 `127.0.0.1`，视频下载保留原有代理策略。
- 自选保存目录，默认使用 `%USERPROFILE%\Downloads\视频素材`。
- 自动下载、合并并检查视频流与音频流；通用下载支持自动最佳、4K、1080p、720p 画质偏好，输出格式取决于原始流。
- 画质选择自动保存在本机；每个任务和失败重试保留原选择，完成后显示实际分辨率。不同画质偏好的成品分别命名，避免复用之前下载的另一档画质。
- HLS 成品若实际是 TS 格式，会无重编码整理为真正的 MP4，便于后续剪辑。
- 下载结束后可在资源管理器中定位文件并把窗口带到前面。
- 下载记录保存在本机，关闭软件后再次打开仍可查看，最多保留最近 500 条。关闭时中断的任务会标为中断，可以重新下载。可一键清理已完成和失败记录；不会删除磁盘中的视频，也不会清除正在进行的任务。
- 单个视频模式，不会因为误贴播放列表而批量下载。
- 支持 `x.com`、`twitter.com` 的推文视频，包括移动版和 `/video/序号` 链接。未指定序号时只取第一个视频；必要时尝试公开备用通道。
- B站会检测原站返回的音视频备用地址，优先同等清晰度下可连接的标准 CDN；代理连接失败时自动尝试直连。
- 抖音支持普通视频、精选页 `modal_id` 和常见分享链接；公开视频优先使用游客通道，受限时尝试一次性匿名会话。
- 小红书支持网页链接和 `xhslink.com` 分享短链。
- 央视频支持 `w.yangshipin.cn/video`、`m.yangshipin.cn/video` 的 `cid` / `vid` 点播分享链接，优先请求公开 1080p，实际清晰度以网站返回为准。
- 央视频使用原站播放地址，下载后检查文件完整性和音画；临时连接失败时重新获取地址并重试一次。
- 失败任务可直接点“重试”；解析不支持、地区限制、登录限制、403 和网络错误分别提示。
- 网站明确要求登录或访问验证时，电脑版会弹窗提醒；访客会话验证与必须登录分别提示。
- 更多动态网页：常规解析失败后，自动尝试识别网页正在播放的公开 MP4 / HLS / DASH 资源，再下载并检查音画。无需选择下载引擎。

## Windows 系统要求

- Windows 10 或 Windows 11，64 位。
- 桌面程序使用 Windows 的 .NET Framework 运行时；构建源码时调用系统自带的 C# 编译器，无需安装开发环境。
- 普通版首次启动需要联网下载约 135 MB 运行组件；完整版已包含这些组件。
- 在中国大陆下载 YouTube 通常需要可用的网络代理；程序会检测常见 Clash 端口及 `HTTP_PROXY` / `HTTPS_PROXY`。

无需安装 Node.js、FFmpeg、Python 或 npm 包。

目前只提供 Windows 10/11 **x64** 可直接使用的版本；macOS、Linux 和 Windows ARM64 暂无发布包。建议将文件夹放在有写入权限的位置，支持中文、空格和方括号路径。

源码发布包默认不包含运行组件，首次启动需要联网准备；如果当前文件夹已经包含所需组件，则不必每次重新下载。下载视频时仍需要联网。

## Windows 快速开始

1. 如果拿到的是压缩包，先右键「全部解压」，再进入下载器文件夹；不要直接在压缩包里运行。
2. 已有 **`梨花下载器.exe`** 时直接双击。若源码包不含 EXE，可在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -Launch` 构建并打开桌面程序。
3. 桌面窗口会显示连接和准备状态。缺少运行组件时，首次启动会联网准备约 135 MB 组件；已有组件时自动启动或连接下载服务。
4. 粘贴视频链接，选择下载画质，按回车或点击「开始下载」。点「更改」选择保存文件夹。
5. 关闭桌面窗口时，下载服务会一并停止。如果有任务正在下载，软件会先询问是否停止下载并退出；选择“否”可继续下载。

如果后台服务未能停止，窗口会保持打开并显示原因。选择停止正在进行的任务会中断下载；已完成的视频不会因为关闭窗口而删除。

## Windows 版如何选择画质

| 选项 | 通用下载的选择方式 |
|---|---|
| 自动最佳（默认） | 下载原站当前允许访问的最佳可用视频和音频 |
| 4K（2160p） | 优先选择不高于 2160p 的最高可用画质 |
| 1080p | 优先选择不高于 1080p 的最高可用画质 |
| 720p | 优先选择不高于 720p 的最高可用画质 |

如果没有不高于目标的版本，就使用原站提供的最小可用版本；直链或只有一个版本的来源保留其原画质。不会转码放大视频，也不会把 720p 变成真正的 4K。任务完成后显示实际宽度和高度，所选档位是偏好，不是对源视频分辨率的保证。

以上偏好用于 B站、YouTube、小红书及其他通用下载通道。B站和 YouTube 选择「自动最佳」或「4K 优先」时，若有已保存的对应网站会话，会先尝试该会话以获取账号有权访问的画质；会话不可用时自动尝试公开方式。YouTube 使用已保存会话时，也会尝试兼容的网页和嵌入式播放接口，以获取该账号和网络下可用的画质；具体版本仍由 YouTube 返回，部分视频或网络可能需要额外验证。若选择了 4K 但最终未取得 4K，任务会提示使用了可用画质。B站和 YouTube 自动最佳及 4K 优先的文件名会包含实际分辨率，重新下载更高画质时不会复用或覆盖原来的低画质文件。抖音和央视频沿用各自的原站画质策略，任务卡片标明「原站画质」。实际可用画质取决于账号权限和原站返回的版本。

[审查记录](docs/AUDIT.md)保留了历史版本的检查结果，不代表当前所有网站都可用。

## 电脑版各网站的工作方式

以下网站一般优先使用表中的公开下载方式，无需一直打开视频网站。B站和 YouTube 的自动最佳和 4K 优先会先尝试已保存会话；小红书公开下载受限时会尝试浏览器会话；其他网站明确要求登录或验证时，尝试已保存的对应网站会话。实际是否可下载仍由网站决定。

| 网站 | 默认方式 | 可能需要的外部条件 |
|---|---|---|
| 抖音 | 游客通道；受限时可启动一次性匿名 Chrome/Edge 会话 | 公开备用流程需要视频可公开播放；匿名浏览器需要本机有 Chrome 或 Edge |
| 小红书 | 公开页面备用 | 链接需要保留网站提供的分享参数；部分笔记可能受限 |
| B站 | yt-dlp 公开下载 | 会员、付费或登录内容需要账号本身拥有权限 |
| X / Twitter | yt-dlp，必要时尝试公开备用通道 | 网络或代理需能访问 X；访问权限和平台风控可能限制下载 |
| YouTube | yt-dlp + Node 挑战运行时 | 网络、代理节点及平台临时风控 |
| 央视频 | 本地解析官方点播分享页及公开播放接口 | 仅支持完整公开的 MP4 点播；直播、试看或受保护格式不支持 |
| 其他视频网页 | yt-dlp 优先；解析失败时用临时 Chrome/Edge 补充识别 | 匿名备用流程需要页面可公开播放，且电脑已有 Chrome 或 Edge |
| MP4 / M3U8 / MPD 直链 | yt-dlp 下载，FFmpeg 合并并检查音画 | 地址未过期，且站点允许下载请求 |

“支持更多网站”不等于“任意链接都能下载”。通用解析覆盖现有 yt-dlp 站点；浏览器补充流程扩展部分动态网页，自动带上该网页的来源地址和浏览器标识。登录、人工验证、付费、DRM、复杂嵌入播放器或多个无法区分的视频仍可能失败。网址以 `blob:` 开头的是浏览器内的临时引用，应粘贴它所在的视频网页地址。

补充识别按需调用电脑已有的浏览器，不增加 npm 包，不另行安装浏览器。一次只识别一个网页，最多排队三个任务；页面识别约 22 秒内结束，启动和清理另有超时限制。识别使用全新的临时目录，用完关闭并清理，不读取日常浏览器资料、不继承账号、不导出 Cookie。常规下载成功时不会启动浏览器。

补充流程只访问公网 http/https 页面和资源，拒绝本机、局域网地址及非标准网页端口。它不会接管已打开的网页、点击登录或处理验证码。某些代理的本地 Fake-IP DNS 模式可能使公开域名被判为非公网，此时会提示无法解析。

央视频的公开备用适配器使用 Node 内置加密库实现播放器请求格式，不下载或执行远程 JavaScript，也不读取浏览器账号。该公开备用通道的页面及视频请求直接连接原站；其他网站保留现有代理行为。

抖音匿名备用流程使用全新的临时浏览器目录，不读取现有 Chrome/Edge 资料，也不登录账号；只在内存中取得当前公开视频地址，任务结束后立即关闭浏览器并清理临时目录。

运行组件使用仓库内固定的版本号和 SHA-256。备用镜像只负责传输文件，不能动态提供“可信校验值”；现有 `bin` 文件也会先校验再执行。

Windows 使用 `bin/yt-dlp.exe` 作为下载引擎，不会因电脑装有 Python 而改用文件夹里残留的旧版 `yt-dlp.pyz`。

## 安装 Chrome / Edge 扩展

扩展与软件一起放在 `browser-extension/`，适用于 Chrome 和 Edge；两个浏览器需要分别安装。当前没有发布到扩展商店，首次使用按以下步骤加载：

1. 启动电脑版，点击界面下方的「安装扩展」，选择 Chrome 或 Edge。
2. 在打开的扩展管理页面开启「开发者模式」，点击「加载已解压的扩展程序」，选择安装提示中的 `browser-extension` 文件夹。扩展文件夹需要保留在原位置。
3. 点击浏览器扩展图标，粘贴下载器提供的配对码并点击「连接」。配对码 10 分钟有效，过期后可再次点击「安装扩展」获取。
4. 在同一浏览器打开并登录要下载的网站，点击扩展中的「同步当前网站」。同步后正常在下载器中粘贴链接；网站会话在本机加密保存，之后可复用。会话失效时重新同步。

扩展需要网站 Cookie 访问权限，只有主动点击「同步当前网站」时才读取当前网站及其必要关联域名；不会自动收集浏览历史。扩展与下载器通过本机连接传递会话，首次配对和请求均受配对码或令牌保护。下载器监听端口变化时，请重新获取配对码连接。

## 登录和 Cookie

- 使用软件本身不需要注册账号。B站和 YouTube 选择自动最佳或 4K 优先时，软件会先尝试已保存的对应网站会话；公开下载失败且网站需要登录或验证时，也可以尝试已保存会话。小红书受限时还会尝试读取本机浏览器会话。扩展同步只在需要时操作一次，下载期间不必一直打开网站。
- 网站可能要求登录、验证或新的访客 Cookie。访客 Cookie 不一定代表需要登录；软件识别到这些限制时会弹窗提示。
- 浏览器读取过程会在内存中处理其 Cookie 数据，仅将目标网站及关联域名的会话使用 Windows 当前用户的系统保护加密，按网站和浏览器保存在 `%LOCALAPPDATA%\视频下载器\浏览器会话`。下次启动软件仍会复用；疑似失效时会尝试重新读取。已有缓存不会在退出软件时清除。
- 浏览器资料可能被锁定或加密：数据库被占用时可完全退出浏览器（包括后台进程）后重试；新版 Chrome 的应用绑定加密也可能阻止读取，关闭窗口不一定能解决。小红书会话不可用时软件会尝试其他浏览器；当前没有通用的账号登录或 Cookie 文件导入界面。
- 会话会发送给对应视频网站以便访问该站，不会上传给软件作者。缓存受 Windows 用户保护，但同一 Windows 用户下的程序仍可能访问；不要分享缓存或浏览器资料。
- 退出浏览器账号或关闭下载器不会自动删除已保存会话；会话仍可能有效，直到网站撤销或其过期。
- 即使浏览器已经登录，也不保证下载器能通过平台验证。[yt-dlp 提醒](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#youtube)使用 YouTube 账号可能受到平台限制。

## 隐私与安全

- 工具不提供公网服务，不向作者的服务器发送链接、账号状态或下载文件。下载时会连接原视频网站；首次安装会连接清单中的上游地址，必要时使用已列出的镜像。
- 下载器一般优先尝试公开下载；B站和 YouTube 选择自动最佳或 4K 优先时会先尝试已保存会话，小红书受限时也会尝试读取浏览器。缓存与本机 Windows 用户关联，不要将其分享给他人。
- 本地网页使用随机会话令牌、Host/来源校验和请求大小限制；其他网页不能调用下载、选目录或资源管理器接口。
- 页面启用内容安全策略，不允许第三方脚本、框架嵌入或跨来源资源。
- 电脑版 `config.json` 保存下载目录、画质设置和下载记录（包括视频链接与保存路径），仅供本机使用，并已被 Git 忽略；不要分享个人配置或浏览器资料。
- 请只下载自己拥有权限或已获授权使用的内容。
- 工具不会绕过付费、会员、私密内容或版权限制。

## 分发方式

源码仓库不提交 `bin/` 和 `config.json`，克隆后由启动脚本自动重建运行环境。若要提供完全离线、双击即用的版本，请把运行组件放进单独的 GitHub Release ZIP，而不是提交到 Git 历史。

Windows 压缩包的区别和下载入口见上面的「版本与文件」。

## 故障排查

- **窗口未连接**：点击窗口右下角「重新连接」；下载服务会在 `3210–3219` 中选择可用端口。
- **源码目录里没有 EXE**：在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1 -Launch`。
- **首次准备失败**：确认网络可访问 GitHub，必要时先启动代理后重试。
- **窗口一直在准备组件**：首次要下载约 135 MB；查看当前下载步骤。失败后可以直接重新双击，已经通过校验的组件会保留。
- **YouTube 风控**：更换代理节点后重新下载，不要把个人 Cookie 写入仓库。
- **抖音游客页受限**：工具会自动尝试匿名临时会话；若仍失败，请确认视频公开，并安装 Chrome 或 Edge。
- **小红书 Cookie 无法读取**：完全退出 Chrome/Edge 后重试，或使用公开分享链接。
- **央视频失败**：复制具体点播视频的官方分享链接；已过期的播放地址会自动重新获取一次。接口结构变化需更新适配器。
- **更多网站失败**：先确认是具体视频页，而非网站首页；工具会自动尝试浏览器补充识别。需要登录、验证码或手动操作的网页可能仍失败；已取得公开 MP4 / M3U8 / MPD 地址时也可直接粘贴。没有 Chrome/Edge 时原有下载路径仍可用。
- **下载结果无法导入剪辑软件**：用 FFmpeg 或播放器确认视频编码；MP4 只是封装格式，不代表一定是 H.264。

## 许可

Node.js、yt-dlp、FFmpeg 等第三方组件遵循各自许可，详情见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

默认源码包不包含第三方运行组件；若将已经下载的 `bin/` 一并转发，需要另行履行对应组件的许可及源码提供义务。

## 更新与卸载

- 更新：先等待任务结束并停止旧服务，再把新启动包解压到新文件夹。旧版配置不会自动迁移，可在新界面重新选择保存位置。
- 下载引擎和运行环境按固定版本校验；不要单独替换 `bin/` 内文件或手动运行 yt-dlp 自更新，否则启动时会恢复清单里的版本。依赖升级通过本项目新版本发布。
- 卸载：停止本目录服务后删除解压文件夹即可。你另选目录保存的视频不会随工具删除。
- 历史变更见 [CHANGELOG.md](docs/CHANGELOG.md)。历史样本成功不代表今天全部平台可用。
